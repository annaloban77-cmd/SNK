# Просмотр результатов проверки

## Карточка документа
Слева — предпросмотр файла, справа — извлечённые поля штампа:
- Обозначение, наименование, формат, масштаб, масса, материал
- Подписи: Разраб. / Пров. / Н.контр. / Утв.
- Технические требования
- Перечень применённых ГОСТ

## Вкладка «Замечания»
Каждое замечание содержит:
- **Критичность**: 🔴 Высокая / 🟡 Средняя / ⚪ Низкая
- **Код правила**: например R-STAMP-001
- **Описание**: что именно не так
- **Требование ГОСТ**: ссылка на пункт стандарта
- **Рекомендация**: как исправить
- Кнопка **«Прочитать ГОСТ»** — открывает текст стандарта

## Действия с замечаниями
- **Подтвердить** — замечание верное
- **Отклонить** — ложное срабатывание (отправляется в тесты для улучшения системы)
- **Исправлено** — ошибка исправлена

## Вкладка «Журнал проверок»
Показывает этапы pipeline: OCR → правила → LLM-семантика с временем каждого этапа.
