# Быстрый старт (5 минут)

## Шаг 1. Загрузите документ
1. Откройте раздел **«Документы»**
2. Нажмите **«Загрузить»**
3. Выберите файл (PDF, PNG, JPEG, DXF, DWG, CDW, SLDPRT)
4. Нажмите **«Загрузить»**

## Шаг 2. Запустите проверку
1. Откройте загруженный документ
2. Нажмите **«Запустить проверку»**
3. Дождитесь результата (обычно 2–10 секунд)

## Шаг 3. Просмотрите замечания
1. Перейдите на вкладку **«Замечания»**
2. Для каждого замечания:
   - **Подтвердить** — замечание верное, требует исправления
   - **Отклонить** — ложное срабатывание (система предложит добавить его в тесты)
   - **Исправлено** — ошибка исправлена в документе

## Шаг 4. Скачайте отчёт
Нажмите **«Скачать отчёт»** — получите HTML-отчёт для печати или CSV для Excel.
