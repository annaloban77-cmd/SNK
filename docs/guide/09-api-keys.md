# API-ключи

## Создание ключа
1. Раздел **«API-ключи»** → **«Создать API-ключ»**
2. Введите название (например «Интеграция с PLM»)
3. Выберите права: чтение / запись / администратор
4. Выберите срок действия: бессрочно / 7 / 30 / 90 / 365 дней / конкретная дата
5. Нажмите **«Создать»**

**Важно!** Ключ показывается только один раз — сохраните его в безопасном месте.

## Использование
```bash
curl -H "Authorization: Bearer nk-your-key-here" \
  https://your-server:1111/api/v1/standards
```

## Отзыв ключа
Нажмите **«Отозвать»** → подтвердите. Ключ перестаёт работать немедленно.

## Срок действия
Ключи с ограниченным сроком автоматически помечаются как «истёк» после даты истечения.
