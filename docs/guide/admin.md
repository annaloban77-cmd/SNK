# Руководство администратора

## 1. Назначение

Это руководство для администраторов системы: установка, настройка, управление пользователями и ключами.

## 2. Термины

| Термин | Объяснение |
|---|---|
| **Инженерная консоль** | Сайт на порту 3333 для настройки системы |
| **OCR-движок** | Программа распознавания текста (PaddleOCR / Tesseract) |
| **db:sync** | Команда синхронизации базы знаний со скриптами |

## 3. Роли и права

| Раздел | Администратор |
|---|---|
| Все разделы | ✅ Полный доступ |
| API-ключи | ✅ Создание, отзыв, удаление |
| Аудит | ✅ Просмотр логов |
| Настройки | ✅ Изменение конфигурации |
| Сырые данные | ✅ JSON штампа |
| Стенд | ✅ Запуск тестов |

## 4. Порядок работы

### Сценарий 1. Установка

![Установка](/guide/img/admin-install.png)

1. Установите Docker и Docker Compose
2. Скачайте docker-compose.yml
3. Запустите: `docker compose up -d`
4. Откройте `http://localhost:1111` — рабочий сайт
5. Откройте `http://localhost:3333` — инженерная консоль

### Сценарий 2. Первый запуск

![Инженерная консоль](/guide/img/admin-console.png)

1. Запустите `bun run db:sync` — заполнит базу знаний (573 стандарта, 460 правил, 4403 справочника)
2. Откройте консоль на порту 3333
3. Проверьте: Система → Status: ok
4. Проверьте: OCR → Engine: paddleocr
5. Создайте организацию в настройках

### Сценарий 3. Управление API-ключами

![API-ключи](/guide/img/admin-apikeys.png)

1. Раздел **«API-ключи»** → **«Создать»**
2. Введите название, выберите права (read/write/admin)
3. Выберите срок (бессрочно / 7 / 30 / 90 / 365 дней)
4. Скопируйте ключ — показывается один раз
5. Для отзыва: кнопка **«Отозвать»** → подтвердить

### Сценарий 4. Управление пользователями

![Пользователи](/guide/img/admin-users.png)

1. Раздел **«Настройки»** → **«Пользователи»**
2. Роли: admin / normocontroller / engineer / viewer
3. Для приглашения: укажите email и роль

### Сценарий 5. Аудит

![Аудит](/guide/img/admin-audit.png)

1. Раздел **«Аудит»** — журнал всех действий
2. Фильтр по типу действия
3. Фильтр по пользователю
4. Автообновление каждые 30 секунд

### Сценарий 6. Настройка OCR

![OCR настройки](/guide/img/admin-ocr.png)

1. Откройте консоль 3333 → раздел OCR
2. Выберите движок: PaddleOCR (точно) / Tesseract (быстро)
3. Настройте: confidence cutoff (0.4), DPI (300), downscale (1000px)
4. Нажмите «Тест OCR» на образце

### Сценарий 7. Настройка моделей LLM

1. Консоль 3333 → раздел Модели
2. Режим: cloud_vlm / local_ollama / off
3. Для локального: Ollama URL + модель (qwen2.5:14b)
4. `local_only: true` — запрещает облачные VLM

### Сценарий 8. Backup и обновление

1. Backup: скопируйте `db/custom.db` и `uploads/`
2. Обновление кода: `git pull && bun install && bun run db:push && bun run db:sync`
3. Перезапуск: `docker compose restart`

## 5. Порты и службы

| Порт | Что | Доступ |
|---|---|---|
| 1111 | Сайт нормоконтролёра | Вся сеть |
| 3333 | Инженерная консоль | Только админ |
| 8100 | OCR sidecar | Только localhost |

## 6. Особые ситуации

### Система не отвечает
1. Проверьте: `docker compose ps`
2. Проверьте логи: `docker compose logs app`
3. Перезапустите: `docker compose restart`

### OCR даёт низкое качество
1. Проверьте доступность PaddleOCR: `curl http://localhost:8100/health`
2. Если недоступен — система использует Tesseract (менее точно)
3. Для PaddleOCR нужно 8+ ГБ RAM

### Тесты красные
1. Запустите `bun run db:sync`
2. Проверьте: Synthetic GREEN 100/100
3. Если красный — не выпускайте обновление

## 7. FAQ

**В: Как часто запускать db:sync?**
О: После каждого обновления кода (git pull).

**В: Что делать, если кончились лимиты?**
О: В настройках измените план (Pro / Enterprise) или увеличьте лимиты.

**В: Как экспортировать данные?**
О: Backup БД (db/custom.db) + папка uploads/. Для отчётов — CSV/HTML из карточки документа.
