# Руководство конструктора

## 1. Назначение

Это руководство для инженеров-конструкторов, которые загружают чертежи на проверку нормоконтроля и работают с замечаниями.

## 2. Термины

| Термин | Объяснение |
|---|---|
| **Нормоконтроль** | Проверка чертежа на соответствие ГОСТ и стандартам |
| **Штамп** | Таблица в правом нижнем углу с обозначением и подписями |
| **Замечание** | Найденное системой несоответствие |
| **Критичность** | Высокая (нельзя выпускать), средняя (исправить), низкая (рекомендация) |

## 3. Быстрый старт (5 минут)

### Шаг 1. Загрузите документ

![Загрузка документа](/guide/img/designer-upload.png)

1. Откройте раздел **«Документы»**
2. Нажмите **«Загрузить»**
3. Выберите файл (PDF, PNG, JPEG, DXF, DWG, CDW, SLDPRT)
4. Нажмите **«Загрузить»**

### Шаг 2. Запустите проверку

![Карточка документа](/guide/img/designer-detail.png)

1. Откройте загруженный документ
2. Нажмите **«Запустить проверку»**
3. Дождитесь результата (2–10 секунд)

### Шаг 3. Просмотрите замечания

![Замечания](/guide/img/designer-issues.png)

Каждое замечание содержит:
- Критичность: высокая / средняя / низкая
- Код правила
- Описание ошибки
- Ссылку на ГОСТ
- Рекомендацию по исправлению

### Шаг 4. Действия с замечаниями

| Действие | Когда применять |
|---|---|
| **Исправлено** | Вы исправили ошибку в документе |
| **Подтвердить** | Замечание верное, но исправление не в вашей компетенции |
| **Отклонить** | Ложное срабатывание (система ошиблась) |

### Шаг 5. Скачайте отчёт

![Скачивание отчёта](/guide/img/designer-report.png)

Нажмите **«Скачать отчёт»** — получите HTML-отчёт для печати или CSV для Excel.

## 4. Требования к качеству скана

| Параметр | Рекомендация | Что будет при нарушении |
|---|---|---|
| DPI | 300 и выше | Мелкий текст не распознаётся |
| Перекос | не более 1° | Текст распознаётся с ошибками |
| Контраст | чёрный на белом | Поля штампа не распознаются |
| Шум | минимальный | Ложные символы |

При низком качестве система покажет предупреждение.

## 5. Поддерживаемые форматы

| Формат | Расширение | Как обрабатывается |
|---|---|---|
| Скан/PDF | .png, .jpg, .pdf | OCR (распознавание текста) |
| DXF | .dxf | Прямой разбор атрибутов |
| DWG | .dwg | Метаданные + текст |
| КОМПАС | .cdw, .spw | Свойства файла |
| SolidWorks | .sldprt, .sldasm, .slddrw | Свойства файла |

## 6. Особые ситуации

### Что делать, если система не распознала штамп?
1. Проверьте качество скана (DPI, перекос)
2. Убедитесь, что штамп в правом нижнем углу
3. Пересканируйте и загрузите заново

### Что делать, если замечание ложное?
Нажмите **«Отклонить»** — система предложит добавить документ в тесты и больше не повторять эту ошибку.

### Что делать, если проверка зависла?
Через 5 минут система автоматически пометит документ как «Ошибка». Нажмите **«Повторить проверку»**.

## 7. FAQ

**В: Можно ли загрузить несколько файлов сразу?**
О: Пока нет, по одному. Пакетная загрузка в планах.

**В: Что значит «CAD-файл требует конвертации»?**
О: Для DWG/CDW/SolidWorks система извлекает метаданные, но не видит геометрию. Для полной проверки экспортируйте в DXF или PDF.

**В: Кто видит мои документы?**
О: Только пользователи вашей организации.
