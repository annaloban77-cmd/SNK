# База знаний

## Стандарты
В системе **573 стандарта**:
- ЕСКД (ГОСТ 2.x) — правила оформления чертежей
- ЕСТД (ГОСТ 3.x) — технологическая документация
- Материалы (ГОСТ 19281, 1050, 380, 4784...)
- Сварка (ГОСТ 5264, 14771, 2.312...)
- Допуски (ГОСТ 25346, 25347, 2789...)
- Судостроение (ОСТ 5, Регистр РС/РР)

## Фильтрация
- По типу: ГОСТ / ОСТ / СТО / РД / Регистр / ЕСКД / СПДС
- По категории: ЕСКД / материалы / сварка / допуски / судостроение / ...
- Поиск по коду или наименованию

## Пункты стандарта
Для ключевых ГОСТ (2.104, 2.301, 2.307 и др.) загружены **пункты** — конкретные требования с номером, текстом и критичностью.

Кнопка **«Прочитать ГОСТ»** в карточке замечания открывает текст стандарта и его пункты.
