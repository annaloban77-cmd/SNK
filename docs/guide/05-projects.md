# Проекты

## Создание проекта
1. Раздел **«Проекты»** → **«Создать проект»**
2. Заполните: код (например «СВ-2025-К-104»), наименование, стадия, описание
3. Нажмите **«Создать»**

## Привязка документов
При загрузке документа выберите проект из списка.
Документы без проекта отображаются с пометкой «Без проекта».

## Фильтр «Без проекта»
В списке документов выберите фильтр «Без проекта» чтобы найти непривязанные документы.

## Стадии разработки
- **ЭП** — эскизный проект
- **ТП** — технический проект
- **РД** — рабочая документация
- **РК** — рабочая для единичного производства
