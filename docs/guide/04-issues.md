# Работа с замечаниями

## Три действия

### Подтвердить
Замечание верное — документ требует исправления.
Статус меняется на «Подтверждено».

### Отклонить
Ложное срабатывание — система нашла проблему там, где её нет.
Что происходит:
1. Статус меняется на «Отклонено»
2. Система создаёт **предложение** добавить этот документ в тесты
3. В разделе «Предложения» (админ) можно одобрить — документ станет тестовым эталоном

Это **обратная связь**: система учится на ошибках и становится точнее.

### Исправлено
Вы исправили документ.
Статус меняется на «Исправлено».

## Feedback loop простыми словами
```
Документ → Проверка → Замечание
                         ↓
                    Отклонено (ложное)
                         ↓
                   Предложение в тесты
                         ↓
                    Одобрено админом
                         ↓
                   Тестовый эталон →
                   Система больше не повторяет эту ошибку
```
