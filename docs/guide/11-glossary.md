# Глоссарий

Без жаргона, простыми словами.

| Термин | Объяснение |
|---|---|
| **Нормоконтроль** | Проверка чертежа на соответствие ГОСТ и стандартам предприятия |
| **Штамп** | Таблица в правом нижнем углу чертежа с обозначением, наименованием, подписями |
| **ГОСТ** | Государственный стандарт — правила оформления документов |
| **ЕСКД** | Единая система конструкторской документации — набор ГОСТ 2.x |
| **Замечание** | Найденное системой несоответствие в документе |
| **Критичность** | Важность замечания: высокая (нельзя выпускать), средняя (нужно исправить), низкая (рекомендация) |
| **OCR** | Распознавание текста на сканах |
| **CAD-файл** | Электронный чертёж (DXF, DWG, CDW, SLDPRT) |
| **Тестовый документ** | Эталонный документ с известными ошибками для проверки системы |
| **Полнота (Recall)** | Какую долю реальных ошибок система нашла |
| **Точность (Precision)** | Какую долю найденных замечаний можно считать верными |
| **Feedback loop** | Цикл: ошибка системы → предложение → улучшение → меньше ошибок |
| **Справочник** | База материалов, крепежа, подшипников и т.д. |
| **Ложное срабатывание** | Система нашла проблему там, где её нет |
| **Пропущенная ошибка** | Система не нашла реальную проблему |
