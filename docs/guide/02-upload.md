# Загрузка документов

## Поддерживаемые форматы

| Формат | Расширение | Как обрабатывается |
|---|---|---|
| Скан/PDF | .png, .jpg, .jpeg, .pdf | OCR (распознавание текста) → извлечение полей штампа |
| DXF | .dxf | Прямой разбор: атрибуты блока штампа, текст, слои |
| DWG | .dwg | Метаданные + текстовые строки из бинарника |
| КОМПАС | .cdw, .spw | Метаданные свойств файла |
| SolidWorks | .sldprt, .sldasm, .slddrw | Метаданные свойств файла |

## Требования к качеству скана

| Параметр | Рекомендация | Что будет при нарушении |
|---|---|---|
| DPI | 300 и выше | Мелкий текст штампа не распознаётся |
| Перекос | не более 1° | Текст распознаётся с ошибками |
| Контраст | чёрный на белом | Поля штампа не распознаются |
| Шум | минимальный | Ложные символы в OCR |

При низком качестве скана система покажет предупреждение и рекомендацию переснять документ.
