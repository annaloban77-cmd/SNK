# Тесты (стенд)

## Зачем нужны тесты
Стенд — это **предохранитель релиза**. Ни одно обновление системы не уходит в продакшн, пока тесты не зелёные.

## Три категории тестов
| Категория | Что тестирует | Документов |
|---|---|---|
| Синтетические | Базовая логика (SVG-чертежи с известными ошибками) | 100 |
| DXF | Разбор CAD-файлов | 20 |
| Реалистичные | Реальные сканы с деградацией (шум, перекос, blur) | 60 |

## Метрики простыми словами
- **Полнота (Recall)** — какую долю реальных ошибок система нашла. 100% = нашла все.
- **Точность (Precision)** — какую долю найденных замечаний можно считать верными. 100% = ни одного ложного.
- **Координатная точность** — насколько точно система указывает место ошибки (в мм).

## Статус
- 🟢 **Зелёный** — можно выпускать (полнота ≥90%, точность ≥85%)
- 🟡 **Жёлтый** — есть проблемы, но работать можно
- 🔴 **Красный** — выпускать нельзя

## Запуск
Нажмите **«Запустить тест»** — система проверит все тестовые документы и покажет метрики.
