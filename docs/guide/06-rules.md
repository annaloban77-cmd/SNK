# Правила нормоконтроля

## Как создать правило без программиста
1. Раздел **«Правила»** → **«Создать правило»**
2. Заполните форму:
   - **Код**: уникальный, например R-MY-001
   - **Наименование**: кратко, что проверяется
   - **Категория**: stamp / material / welding / tolerances / ...
   - **Метод**: deterministic (точно) или semantic (смысловой анализ)
   - **Критичность**: высокая / средняя / низкая
   - **ГОСТ**: выберите из базы знаний
3. Нажмите **«Проверить на тестах»** — система прогонит правило по тестовым документам и покажет: сколько замечаний найдено, нет ли ложных срабатываний
4. Если результат устраивает — **«Сохранить»**

## Отключение правила
Переключите тумблер «Вкл/Выкл» в строке правила.

## Редактирование
Нажмите на строку правила → откроется форма редактирования.

## Категории правил
| Категория | Что проверяет |
|---|---|
| stamp | Поля штампа (обозначение, наименование, подписи, дата) |
| material | Материалы и их соответствие ГОСТ |
| welding | Сварные швы (обозначения, катеты, контроль) |
| format | Формат листа, рамка |
| tolerances | Допуски, посадки, шероховатость |
| specification | Спецификации (разделы, позиции, количество) |
| cad_attr | Атрибуты CAD-файлов |
| geometry | Виды, разрезы, сечения |
| semantic | Смысловые противоречия (через LLM) |
| shipbuilding | Судостроительные требования (Регистр, корпус, трубы) |
