    68→## 2. GET `/api/documents?status=&format=&sourceType=&projectId=&search=&page=1&pageSize=20`
    69→Query-параметры (все опциональные):
    70→- `status`: new | processing | analyzed | failed
    71→- `format`: A0|A1|A2|A3|A4|unknown
    72→- `sourceType`: scan|pdf|dwg|dxf|cdw|sldprt|sldasm|slddrw|spw
    73→- `projectId`: string
    74→- `search`: строка поиска по name/designation
    75→- `page`, `pageSize`: пагинация (default 1 / 20)
    76→
    77→Возвращает:
    78→```ts
    79→{ items: DocumentDto[], total: number, page: number, pageSize: number }
    80→```
    81→
    82→DocumentDto (см. `src/lib/types.ts`):
    83→```ts
    84→{
    85→  id, projectId, name, originalName, mimeType, size, format, sourceType,
    86→  status, stamp: StampFields | null, ocrText: string | null,
    87→  issueCount, highCount, mediumCount, lowCount, checkDuration: number | null,
    88→  docTypeId: string | null, project: { id, code, name } | null,
    89→  createdAt: string (ISO), updatedAt: string (ISO)
    90→}
    91→```
    92→StampFields = JSON-объект: `{ format, designation, name, scale, mass, material, letter, stage, signatures:{developed,checked,normControl,approved}, dates:{developed,checked,approved}, invNumber, technicalRequirements: string[], gostReferences: string[], documentType, sheetCount, notes }`. В БД хранится в `Document.stampJson` как строка — парсить в `stamp` при возврате.

    97→## 4. POST `/api/documents/upload` (multipart/form-data)
    98→Поля формы:
    99→- `file`: File (обязательно) — PDF/PNG/JPEG/SVG или CAD-файл
   100→- `projectId`: string (опционально)
   101→- `sourceType`: string (опционально, иначе определяется по расширению/mime)
   102→- `format`: string (опционально, иначе 'unknown')
   103→
   104→Логика:
   105→- Сохранить файл в `/home/z/my-project/uploads/<cuid>-<sanitized-name>`
   106→- Определить sourceType по расширению (.pdf→pdf, .png/.jpg/.jpeg→scan, .dwg→dwg, .dxf→dxf, .cdw→cdw, .sldprt→sldprt, .sldasm→sldasm, .slddrw→slddrw, .spw→spw)
   107→- Определить format: для изображений/PDF можно попробовать вычислить из пропорций (по желанию), иначе 'unknown'
   108→- Создать Document со status='new'
   109→- Вернуть `{ document: DocumentDto }`
   110→
   111→## 5. POST `/api/documents/[id]/analyze`
   112→Тело: `{ runLlm?: boolean = true }` (опционально)
   113→
   114→Логика:
   115→1. Поставить status='processing', записать CheckLog(stage='upload', status='started')
   116→2. Прочитать файл с диска. Если это изображение (PNG/JPEG) — конвертировать в data URL (base64). Если PDF — рендерить первую страницу в PNG через `sharp` (если недоступно — пропустить VLM с пометкой) и затем в data URL. Если CAD-файл — пропустить VLM-шаг, оставить stamp=null.
   117→3. Если есть data URL — вызвать `extractStampFromImage(dataUrl)` из `@/lib/zai`
   118→   - Записать CheckLog(stage='vlm_extract', status='success'|'failed', durationMs)
   119→   - Сохранить результат в `Document.stampJson = JSON.stringify(stamp)`
   120→4. Если stamp извлечён — запустить `runDeterministicRules(toStampFields(stamp))` из `@/lib/rules`
   121→   - Записать CheckLog(stage='rules_check', ...)
   122→5. Если `runLlm !== false` и stamp извлечён — вызвать `llmSemanticCheck(stamp, stamp.gostReferences || [])`
   123→   - Записать CheckLog(stage='llm_semantic', ...)
   124→6. Удалить старые Issue для этого документа (status='new'..'auto') и записать новые (из детерминированных + LLM)
   125→7. Пересчитать `issueCount`, `highCount`, `mediumCount`, `lowCount`
   126→8. Поставить status='analyzed', записать CheckLog(stage='report', status='success')
   127→9. Вернуть `AnalyzeResponse`:
   128→```ts
   129→{
   130→  documentId, status: 'analyzed', stamp: StampFields | null,
   131→  issues: IssueDto[], checkDurationMs: number,
   132→  stages: [{ stage, status, durationMs: number | null, message?: string }]
   133→}
   134→```
   135→При ошибке — status='failed', CheckLog(stage, status='failed', message=error), HTTP 200 с `{ error: string }` (но не 500, чтобы фронтенд мог показать).
