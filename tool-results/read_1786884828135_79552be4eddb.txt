    68→    68→## 2. GET `/api/documents?status=&format=&sourceType=&projectId=&search=&page=1&pageSize=20`
    69→    69→Query-параметры (все опциональные):
    70→    70→- `status`: new | processing | analyzed | failed
    71→    71→- `format`: A0|A1|A2|A3|A4|unknown
    72→    72→- `sourceType`: scan|pdf|dwg|dxf|cdw|sldprt|sldasm|slddrw|spw
    73→    73→- `projectId`: string
    74→    74→- `search`: строка поиска по name/designation
    75→    75→- `page`, `pageSize`: пагинация (default 1 / 20)
    76→    76→
    77→    77→Возвращает:
    78→    78→```ts
    79→    79→{ items: DocumentDto[], total: number, page: number, pageSize: number }
    80→    80→```
    81→    81→
    82→    82→DocumentDto (см. `src/lib/types.ts`):
    83→    83→```ts
    84→    84→{
    85→    85→  id, projectId, name, originalName, mimeType, size, format, sourceType,
    86→    86→  status, stamp: StampFields | null, ocrText: string | null,
    87→    87→  issueCount, highCount, mediumCount, lowCount, checkDuration: number | null,
    88→    88→  docTypeId: string | null, project: { id, code, name } | null,
    89→    89→  createdAt: string (ISO), updatedAt: string (ISO)
    90→    90→}
    91→    91→```
    92→    92→StampFields = JSON-объект: `{ format, designation, name, scale, mass, material, letter, stage, signatures:{developed,checked,normControl,approved}, dates:{developed,checked,approved}, invNumber, technicalRequirements: string[], gostReferences: string[], documentType, sheetCount, notes }`. В БД хранится в `Document.stampJson` как строка — парсить в `stamp` при возврате.

    97→    97→## 4. POST `/api/documents/upload` (multipart/form-data)
    98→    98→Поля формы:
    99→    99→- `file`: File (обязательно) — PDF/PNG/JPEG/SVG или CAD-файл
   100→   100→- `projectId`: string (опционально)
   101→   101→- `sourceType`: string (опционально, иначе определяется по расширению/mime)
   102→   102→- `format`: string (опционально, иначе 'unknown')
   103→   103→
   104→   104→Логика:
   105→   105→- Сохранить файл в `/home/z/my-project/uploads/<cuid>-<sanitized-name>`
   106→   106→- Определить sourceType по расширению (.pdf→pdf, .png/.jpg/.jpeg→scan, .dwg→dwg, .dxf→dxf, .cdw→cdw, .sldprt→sldprt, .sldasm→sldasm, .slddrw→slddrw, .spw→spw)
   107→   107→- Определить format: для изображений/PDF можно попробовать вычислить из пропорций (по желанию), иначе 'unknown'
   108→   108→- Создать Document со status='new'
   109→   109→- Вернуть `{ document: DocumentDto }`
   110→   110→
   111→   111→## 5. POST `/api/documents/[id]/analyze`
   112→   112→Тело: `{ runLlm?: boolean = true }` (опционально)
   113→   113→
   114→   114→Логика:
   115→   115→1. Поставить status='processing', записать CheckLog(stage='upload', status='started')
   116→   116→2. Прочитать файл с диска. Если это изображение (PNG/JPEG) — конвертировать в data URL (base64). Если PDF — рендерить первую страницу в PNG через `sharp` (если недоступно — пропустить VLM с пометкой) и затем в data URL. Если CAD-файл — пропустить VLM-шаг, оставить stamp=null.
   117→   117→3. Если есть data URL — вызвать `extractStampFromImage(dataUrl)` из `@/lib/zai`
   118→   118→   - Записать CheckLog(stage='vlm_extract', status='success'|'failed', durationMs)
   119→   119→   - Сохранить результат в `Document.stampJson = JSON.stringify(stamp)`
   120→   120→4. Если stamp извлечён — запустить `runDeterministicRules(toStampFields(stamp))` из `@/lib/rules`
   121→   121→   - Записать CheckLog(stage='rules_check', ...)
   122→   122→5. Если `runLlm !== false` и stamp извлечён — вызвать `llmSemanticCheck(stamp, stamp.gostReferences || [])`
   123→   123→   - Записать CheckLog(stage='llm_semantic', ...)
   124→   124→6. Удалить старые Issue для этого документа (status='new'..'auto') и записать новые (из детерминированных + LLM)
   125→   125→7. Пересчитать `issueCount`, `highCount`, `mediumCount`, `lowCount`
   126→   126→8. Поставить status='analyzed', записать CheckLog(stage='report', status='success')
   127→   127→9. Вернуть `AnalyzeResponse`:
   128→   128→```ts
   129→   129→{
   130→   130→  documentId, status: 'analyzed', stamp: StampFields | null,
   131→   131→  issues: IssueDto[], checkDurationMs: number,
   132→   132→  stages: [{ stage, status, durationMs: number | null, message?: string }]
   133→   133→}
   134→   134→```
   135→   135→При ошибке — status='failed', CheckLog(stage, status='failed', message=error), HTTP 200 с `{ error: string }` (но не 500, чтобы фронтенд мог показать).
