### Бенч (стенд)
- **Синтетический бенч**: 🟢 GREEN — 100/100, Recall 100%, Precision 100%, 0.05с
- **DXF-бенч**: 🟢 GREEN — 20/20, Recall 100%, Precision 100%, 0.03с
- **Деградированный бенч**: 🔴 RED — Precision 100%, Recall 0% (Tesseract limitation)
- 150 тестовых семплов всего

### OCR Pipeline
- SVG-парсер (для bench-семплов) — 100% точно, мгновенно
- Zone-OCR (Tesseract.js) — для реальных сканов, с препроцессингом
  - Otsu binarization
  - Frame detection для точного позиционирования штампа
  - Ink detection (проверка наличия тёмных пикселей в зонах полей)
  - Per-field confidence tracking
- VLM fallback (только крайний случай, логируется)
- Post-filter: confidence-aware, дедупликация, drop-low-if-high

### CAD-парсер
- DXF: полный разбор (ATTDEF блоки, TEXT entities, слои, координаты)
  - Извлечение штампа из TITLE_BLOCK с ATTDEF
  - Извлечение ГОСТ и ТТ из TEXT entities
  - UTF-8 кодировка
- DWG: метаданные (версия AutoCAD, текстовые строки)
- SolidWorks (SLDPRT/SLDASM/SLDDRW): свойства файла
- КОМПАС (CDW/SPW): свойства файла

### Рабочий цикл нормоконтролёра
- Загрузка документа → автоматическая проверка → замечания → акт
- Статусы: new → processing → analyzed → (confirmed/rejected/fixed)
- Feedback-петля: отклонённые FP → добавить в бенч → улучшить систему
- Отчёты: HTML (print-ready A4) + CSV (Excel)
- Проекты: группировка документов, сводка

### Multi-tenant и монетизация
- Организации с профилями (свои правила, эталоны)
- Роли: admin / normocontroller / engineer / viewer
- API-ключи: read / write / admin scopes, rate limits
- Подписки: Старт (0₽) / Профи (49 500₽/мес) / Предприятие (199 500₽/мес)
- Публичный API: /api/v1/* с Bearer token авторизацией
- Аудит-лог всех действий

### Бизнес-метрики
- Среднее время проверки
- % документов, прошедших с первого раза
- Топ-10 ошибок
- Тренд по неделям
- Оценка сэкономленных человеко-часов и стоимости

## Известные ограничения

1. **Tesseract на деградированных сканах**: OCR confidence 18-30%, текст нераспознаваем. Для достижения Recall ≥85% на деградированных изображениях требуется более мощный OCR (PaddleOCR, ABBYY, или custom CNN).
2. **DWG/CDW/SolidWorks**: только метаданные, не полный разбор геометрии. Для полного разбора требуется ODA SDK / SolidWorks API / КОМПАС API.
3. **VLM**: используется только как fallback (крайний случай) и для семантических проверок (объяснения). Не для детекции — P5 соблюдён.
